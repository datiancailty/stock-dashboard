# 我的分红工具：当前版本摘要（公共脱敏版）

对应 Release：`v2026.09.13.3`。完整运维交接仅在私有维护归档，不在本公共源码或Pages中。

## 本版范围

- 补齐当前功能、模块职责、已经完成的问题、未解决/阻塞、刻意停用、证据时间线和续接纪律。
- 建立“每次变更同步最新MD、每个Release保存对应冻结MD”的规则。私有归档有文档hash、证据截止、任务分类及源码清单校验；发布后由独立receipt绑定tag/commit/附件，避免循环hash。
- 独立VPS状态计划从每20分钟改为**周一至周五北京时间10:05、11:55、15:20**，分别比策略计划09:35、11:25、14:50晚30分钟；不增加第四次，不周末运行，错过不补跑。
- 正常策略/备份调度继续停用，交易授权不变。状态服务不触发行情、账户、订单或控制激活，不把新心跳时间当成新策略数据。
- 本版公共差异只有说明文档；HTML/JS/CSS、数据采集与分红算法不改。本机已验收Worker保持原不可变执行包，不能把文档tag变化理解成全部运行包升级。

## 当前功能

- Part0只读状态展示，Part1是唯一自选编辑入口；个人保存清单、VPS目标revision和实际激活回执是不同状态。
- Part2技术指标、Part3分红价格网格、Part4日历、Part5公告及历史研究、Part6操作/反馈使用认证私有数据。
- 本机确定性六阶段更新独立于AI；AI新分析/画像演化暂停，历史建议结果的机械观察保留。
- 可靠前瞻优先、已核实现金回退，缺失保持空值，不将回退伪装成预测成功。

## 仍未解决 / 不得夸大

- 状态首次送达有间歇未确认，旧报告后来成功不等于根因已解决；新低频计划尚须真实计划触发验证。
- 前端仍用“超过30分钟”标示回执较旧；低频日程/周末会自然超过该阈值。本版未修改此显示逻辑，提示较旧不证明VPS故障。
- 降频保留原不超过25分钟的有限重试窗口；下一计划通常不会重发过期未知报告。它不是送达稳定性的修复。
- 生产登录页面的最新目视验收与未来自动运行不能由离线测试或HTTP字节校验代替。
- 白名单自动提交/激活与未来策略试运行仍未启用；保存个人清单不能变成交易授权。

## 刻意停用，不是待修复

旧公共行情/新闻/AI自检工作流、AI/Codex自动分析、正常策略timer、backup timer、ARM、过期trial与旧恢复脚本继续停用。历史SQL、ACK和已经完成的补更不能因旧日志再次执行。

## 版本与归档规则

1. 后续每次变更必须同步当前MD的功能/状态/证据截止，不以文件mtime代替内容完整性。
2. 私有完整MD与逐tag冻结副本字节相同；不同版本不得覆盖或移动旧tag。
3. 公共Release只附本脱敏MD；完整运维目录、私有记录、凭据、数据库及原始日志不得公开。
4. 发布后读回tag/commit与附件实际字节。源码、Pages、本机调度、Hosted、VPS、真实运行分别验收。
5. 最新入口优先；旧README/历史版本只作取证，不应驱动恢复已经停用的任务。
