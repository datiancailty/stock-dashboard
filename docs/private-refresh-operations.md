# 私有看板：确定性每日更新

本页面的业务数据由本机普通 Python 任务写入 Supabase。GitHub Pages 只发布界面代码；不依赖 OpenAI、Codex 或 MX 金融查询来维持每日更新。AI 画像和新策略分析保持暂停，历史建议的机械结果观察独立运行。此文不包含业务记录或凭据。

## 数据与口径

- Part 1 的私有自选清单是采集范围；刷新不修改自选、持仓、交易记录或反馈，也不修改独立的 VPS 白名单。
- 行情：HiThink 优先，失败后尝试经过日期及全量覆盖校验的公开行情；供应商快照就绪时间不等于逐证券成交时间。
- 技术指标：HiThink 前复权日线计算原 Dashboard 周 BOLL（20、2、样本标准差、ISO 周最后收盘、含当前周）；不复权日线计算日／周／月位置。只使用已完成日线，指标日期单独展示，不覆盖 Tushare 原始归档。
- 分红：可靠的最新年度＋最新中期前瞻优先；没有可靠前瞻则使用已核实的近12个月人民币税前已实施现金分红。新中期替换旧中期，不把 TTM 再机械加上未来一笔。两个口径独立保存，未知不是零。
- 公司公告：公开公告索引增量采集并保留旧记录，不等价于全媒体 AI 新闻搜索。已公告待实施不标成已派发；来源不全不填数。
- 历史建议观察：保留原始建议及身份，不新增 AI 建议；属于不复权价格观察，不是含分红投资收益回测。

## 调度与状态

独立版本目录位于 `~/.hermes/workspace/stock-dashboard-releases/`，运行前校验文件 SHA-256。已授权安装时，`current` 原子指向一个只读版本，LaunchAgent 不指向日常编辑目录。

- 工作日北京时间 18:05，一次更新。
- `RunAtLoad` 处理开机；错过的 `StartCalendarInterval` 在醒来后合并触发。取最近到期的工作日槽，补采一次最新数据，不逐日重放，不强制唤醒，不用10分钟轮询。
- 实时行情的交易日与技术指标“日线已完成”日期不同，盘中补跑不能拿昨日日线日期误拒当天实时备用行情。
- 同槽先记录尝试；失败不推进完整成功日期；同槽不无限自动重跑。只读请求有限重试，写入失败先核对读回，不能盲目重复写。
- 每个阶段向独立私有健康接口上报开始／成功／失败和脱敏原因。网页可见时每15分钟读回，关闭页面不轮询；网页刷新不是重新采集。
- 电脑关机或网络完全中断时无法上报新错误；网页会显示回执过期，不能仅凭网页区分关机和断网。

健康记录不复用 AI health，不写入 GitHub，不含 API Key、异常原文、账户详情或原始响应。来源缺证据与采集／写入故障分开：前者保留明确空值，后者保留上次成功数据并报告失败。

## 停止与恢复边界

停止新任务（不会删除 Supabase 业务数据）：

```sh
launchctl bootout "gui/$(id -u)/com.datiancailty.stock-dashboard.refresh-daily"
```

不要将恢复理解为重新开启旧 GitHub live 写入或旧 MX future 任务。源代码、Hosted 前向结构、私有数据、Pages 发布和本机调度是不同回滚边界；任何数据库结构变更仍由用户本人手动执行 SQL。

凭据沿用本机既有的 owner-only 文件／Keychain，不进入 plist、命令行参数、日志或 Git。跨进程刷新同一 Supabase 会话时使用短排他锁，避免并发轮换覆盖 Keychain。

## 中断恢复与独立 VPS 状态

每日任务在每个阶段开始和结束时原子记录本机检查点。电脑重启、断电或强制结束后的同槽旧尝试，不会被当成已完成；也不会自动重放结果未知的私有写入。下一个到期工作日仍可正常运行，额外补更须先读回核对再由用户授权。阶段超时会终止该阶段的独立进程组，保留已经成功的阶段，并继续处理其余独立阶段；不完整结果不能推进完整成功日期。

Part3桥接使用与当前已激活股票池逐一核对的正常配置，保留源证据时间和空值语义。正常控制面与历史日期试运行的配置、release和timer不是同一入口；不得为了恢复镜像去启动旧试运行。

VPS的独立状态任务可以每20分钟读取正常systemd/SQLite状态并向私有控制面上报，但不会触发策略、行情、账户或订单接口。新的状态检查时间不是新的策略/行情/账户观测时间；旧观测日期和未知健康状态必须保留。源码包、远端安装、首次上报、后续定时触发分别验收。

## 验收

发布必须分别有：离线测试、真实采集、认证私有读回和保留性检查、生产精确版本资产、登录后的页面检查、旧任务停用／新任务加载证据。一次手工成功不能冒充未来日期已经执行，也不能保证外部供应商永不故障。历史公开数据清理是另行授权的独立工作，不随此版本改写 Git 历史。
